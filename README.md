## Quick Start Guide

### 1. Requirements
- PHP 8.2+
- MySQL Server (XAMPP running on `127.0.0.1:3306`)
- Apache Server (XAMPP)

### 2. Run Project
Ensure MySQL is active in the XAMPP control panel.

**Option A (Direct via XAMPP):**
```
http://localhost/travel-booking/public/
```

**Option B (via Artisan):**
```bash
php artisan serve
```
Open browser at: `http://127.0.0.1:8000`
